# Securing the Software Supply Chain

Supply chain security protects the software, dependencies, build system, and artifacts that your application depends on.

## Common Risks

- dependency confusion,
- malicious packages,
- typosquatting,
- compromised CI secrets,
- modified build artifacts,
- unsigned images,
- and weak provenance.

## Real Incidents To Study

- SolarWinds showed how trusted update systems can become an attack path.
- Codecov showed how CI secrets can be exposed through compromised tooling.
- XZ Utils showed how patient attackers can target open source supply chains.

## Controls

- generate SBOMs,
- use SLSA principles,
- sign artifacts with Sigstore or Cosign,
- verify provenance,
- pin dependencies,
- and restrict package registry sources.

```bash
cosign sign --key cosign.key registry.example.com/app:1.0.0
cosign verify --key cosign.pub registry.example.com/app:1.0.0
```
