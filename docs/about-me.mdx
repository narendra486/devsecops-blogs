# About Me

Author: Narendra Palla  
Role: Product Security Engineer

I write this platform from both engineering and security point of view.

The goal is to explain CI/CD Security, DevSecOps, SCM Security, GitHub Actions Security, Application Security, and Software Supply Chain Security in simple practical language.

This site is for:

- Developers,
- DevOps engineers,
- Platform engineers,
- Product security engineers,
- AppSec engineers,
- Security champions,
- Students learning DevSecOps.

The writing style is simple: explain the problem, show where it fails in real pipelines, add code examples, and explain how to fix it properly.
