# Hardening GitHub Actions Pipelines

GitHub Actions is powerful because it can build, test, scan, publish, and deploy.

That also makes it sensitive.

## Baseline Controls

- set least privilege permissions,
- pin third-party actions,
- avoid secrets in pull requests from forks,
- use OIDC instead of long-lived cloud keys,
- protect environments,
- use required reviews,
- separate build and deploy workflows,
- and harden self-hosted runners.

## Example Permissions

```yaml
permissions:
  contents: read
  security-events: write
  pull-requests: write
```

Do not use broad write permissions unless the job needs them.
