# CI Security Overview

CI security protects the build system.

This includes workflow permissions, runners, secrets, artifacts, dependency installation, SBOM generation, and scanner execution.

## Basic Secure CI YAML

```yaml
name: secure-ci

on:
  pull_request:
  push:
    branches: [main]

permissions:
  contents: read
  security-events: write

jobs:
  build-test-scan:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout source
        uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 24
          cache: npm

      - name: Install dependencies
        run: npm ci

      - name: Run tests
        run: npm test --if-present

      - name: Build
        run: npm run build --if-present
```

## Explanation

The workflow starts with least privilege permissions.

It runs on pull requests and main branch pushes.

It uses `npm ci` instead of `npm install` because CI should install from the lock file.

Deep scans can be added after build and test, depending on the application type.
