# GitHub Security Best Practices

GitHub security is not only about scanners.

Repository settings, branch protection, rulesets, workflow permissions, CODEOWNERS, Dependabot, and reusable workflows decide how safely teams can merge and deploy.

## Repository Baseline YAML

```yaml
github_security_baseline:
  branch_protection:
    main:
      require_pull_request: true
      require_approvals: 1
      require_codeowners: true
      require_status_checks:
        - tests
        - pr-security
        - secret-scan
      block_force_push: true
      block_deletion: true

  actions:
    default_token_permissions: read
    require_pinned_actions: true
    allow_reusable_workflows: true

  dependabot:
    enabled: true
    schedule: weekly

  codeowners:
    enabled: true
```

## Explanation

Branch protection protects the main branch.

Required checks make sure security workflows are not optional.

CODEOWNERS adds ownership for sensitive paths.

Pinned actions reduce supply chain risk from changing third-party action versions.
