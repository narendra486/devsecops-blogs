# Scanner Purpose Map

Do not introduce scanners by tool name first.

Introduce the risk first, then the scanner.

| Risk | Scanner Category | Example Tools |
| --- | --- | --- |
| Insecure code | SAST | CodeQL, Semgrep, Snyk Code, SonarQube |
| Vulnerable dependency | SCA | Dependabot, Snyk Open Source, Trivy, OSV Scanner |
| Leaked credentials | Secret scanning | Gitleaks, TruffleHog, GitHub Secret Scanning |
| Cloud misconfiguration | IaC scanning | Checkov, Trivy, tfsec, KICS |
| Vulnerable image | Container scanning | Trivy, Grype |

This keeps the blog architecture-driven, not tool-centric.
